# Review delivery amendment — 2 October 2026

The investigator requested offline Markdown packets and allowed up to ten
reviewers after difficulties accessing the local review site. The fixed sample,
source/rewrite texts, and two ratings per sampled pair are unchanged. Existing
issued forms, site drafts and prior source evidence are retained.

Eight meaning reviewers receive 405 pairs each. The 1,620 sampled pairs are
divided into four blocks of 405; each block has two distinct assigned reviewers.
Within every model/author/work/condition stratum, its five existing sampled pairs
are hash-ordered, one goes to each block, and the extra pair rotates across
blocks. This distributes all 324 strata across all four blocks. The partition
does not use classifier results, significance, observed rating quality or
preferences about outputs. Each person's display order is separately hashed.

A ninth, separate reviewer checks the four replacement source passages. A tenth
reviewer is reserved for disputed judgments after initial returns exist. The
adjudication packet cannot be populated before those disagreements are observed.

Each completed Markdown file remains an original private return. The importer
checks every identifier, source text and source context against its issued
template, and converts only response fields into canonical CSV/JSONL. It records
each actual person's identity reference, reported completion timestamp, received
timestamp and investigator-recorded origin separately. Markdown content or file
delivery alone does not establish independent person-origin evidence. Assisted
work can be retained explicitly as assisted but cannot satisfy that gate.

The study therefore has eight meaning raters, not two people who each reviewed
the entire sample. Kappa is computed within each fixed reviewer pair, by model.
Pooled role agreement is descriptive raw agreement; pooled kappa is not reported
as reliability between two actual people. The underlying two original opaque
item-ID namespaces serve only as assignment lineage. The primary semantic
sensitivity retains the union of the two original risk ratings. Adjudication
does not silently erase either rating or change that primary rule.

No new judgments are generated by this delivery amendment. Completion and
scientific conclusions remain dependent on the actual returned reviews and the
subsequent checks already specified in the primary analysis plan.
