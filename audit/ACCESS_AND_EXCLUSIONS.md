# Access, exclusions and release boundaries

This public repository is a computational audit package. It includes the corrected source corpus, six active generation arms, recorded requests/outcomes and failures, frozen scientific code, analysis predictions/transforms/results, aggregate research tables/figures, references and verification records. The manifest identifies the files actually included; this document does not imply that every local research file is public.

## Material held locally

| Material | Current treatment |
| --- | --- |
| Current manuscript text, DOCX/PDF and supplement documents; manuscript document builder | Excluded at the author's request. Research tables/figures and reference metadata are included separately. |
| Complete local author package and full reviewed ZIP archive | Excluded. The repository supplies an explicit public selection rather than uploading either complete archive. |
| Individual reviewer ratings, detailed risk flags/adjudication, source-review verdicts and raw returns | Withheld pending resolution of written permission for the proposed disclosure and the applicable ethics basis. |
| Participant identities, contact details, private notes, recruitment/consent records and author confirmation records | Withheld. No public record should contain participant names or signatures. |
| API keys, tokens, environment files, access credentials and assignment/account secrets | Excluded. Users conducting new generation obtain their own access and cover their own provider costs. |

The investigator reports verbal research-use consent and willingness to provide later written confirmation. Written confirmations and an institutional approval/exemption determination have not been supplied. A later confirmation must preserve its actual date and scope. These unresolved matters are not represented as completed certifications in this repository.

## What public verification can establish

Public data support exact checks of selected literary passages, recorded generation inputs/outcomes, first-outcome failure accounting, fixed work folds, primary numerical analyses and the documented transfer/geometry verification scopes. They support reconstruction of the primary 54-test family and computational comparisons with frozen result files.

The aggregate semantic tables remain visible for inspection, but the public package cannot reconstruct the participant-level flags, fixed-dyad agreement or every semantic exclusion. It also cannot independently inspect the withheld source-review decisions. Public source-span checks establish textual provenance, not a fresh independent judgment about every excerpt's authorship or suitability.

Hashes and successful computations do not establish participant identity, independent completion, consent, ethics approval or absence of assistance. The session generation designation is preserved as recorded provenance; its underlying model checkpoint is not independently attested. No claim of misconduct or of certified absence of misconduct follows from these computational checks.

## Rights and licenses

No new blanket license is applied to the complete tree in this release. The original contributor's code/data/figure license choices remain pending. Existing third-party license notices, including any retained legacy code notices, keep their original scope. A repository's public visibility does not itself grant unrestricted reuse.

Historical literary editions retain their archive/source notices and copyright conditions. Their status must be checked in the user's jurisdiction; the study author does not claim ownership of the underlying literary works. Recorded model outputs and responses may also be subject to provider terms. Participant-related material requires the applicable permission and privacy safeguards before any future disclosure. A later license for original code, tables or figures cannot override those separate rights.

No API credential is licensed or provided. A new generation run is a separate paid workflow; the offline audit commands require no such access. No archival DOI or completed public Zenodo deposit is claimed here.

## Historical material

`old stuff/` preserves earlier material that was already public so changes remain traceable. It is not the current source of truth for v3 numbers or instructions. Files kept there do not override the current protocol, lineage, manifest or this release's exclusions. Git history retains earlier paths and revisions; moving a file is not deletion of its public history.

For an audit requiring the withheld records, contact the corresponding researcher through the repository's normal contact route. Any access must be arranged only after the relevant permissions and ethics basis are resolved. This document does not promise that participant-level records can be released publicly.
