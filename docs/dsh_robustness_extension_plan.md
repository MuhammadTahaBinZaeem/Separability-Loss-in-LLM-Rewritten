# DSH Robustness Extension Plan

## Purpose

This document tracks the post-freeze robustness extension for the `litpaper` project. The original 20-step empirical core remains frozen unless a factual or reproducibility-breaking issue is found. The extension exists to improve the odds of a serious submission to **Digital Scholarship in the Humanities** by directly addressing likely reviewer objections.

The extension is not a new paper direction. It strengthens the same core claim:

> Controlled LLM rewriting contracts measurable authorial style separability in a balanced public-domain fiction corpus, while leaving residual author-specific structure under same-condition analysis.

## Reviewer objections targeted

| Objection | Extension answer |
|---|---|
| The result may be a single-model Gemini effect. | Add multi-LLM replication across GPT-4o, Gemini 1.5 Pro, and Claude Sonnet 3.5, with repeated runs where deterministic seeding is unavailable. |
| The model may be measuring work/topic rather than author. | **Completed E2:** leave-one-work-out validation now tests cross-work generalisation. The result is mixed but useful: original cross-work macro-F1 is moderate, while rewrite losses and distance contraction remain directionally stable. |
| QC warning rows may drive the result. | **Completed E3:** Step 15-19-style metrics were recomputed on all rows, QC-pass-only rows, and rows excluding hard length warnings. The central transfer-loss and distance-contraction directions remained stable. |
| The rewrite protocol promises semantic fidelity but does not prove it. | Add a human semantic-fidelity annotation audit on a 10% sample of rewrites. |
| The paper lacks humanities-facing reader evidence. | Add a human reading study measuring readability, perceived style distinctiveness, AI/human judgement, and same-author similarity. |
| Prompt blinding is asserted but not empirically justified. | Add a smaller author-revealed prompt ablation. |
| Passage length may partly explain degradation. | **Completed E7:** length-band robustness shows transfer-loss persistence in source-original length bands, while documenting that actual rewritten lengths often shift shorter. |
| Feature-family results show vulnerability but not full-system dependence. | **E8 infrastructure added:** leave-one-feature-family-out ablation now has a locked protocol, runnable script, checker, and workflow; outputs still need to be generated by workflow. |

## E2 completion summary

E2 generated and committed the held-out-work validation package in commit `572cbc9a73d2caca1b7f1b2bdb034a78ba2c4ec3`, with workflow proof log `logs/e2_heldout_work_validation_workflow_proof.md`.

Main result:

- nearest-centroid held-out original macro-F1 is `0.601154`, so cross-work author classification is moderate rather than strong;
- nearest-centroid held-out transfer losses remain positive: paraphrase `0.179796`, modernize `0.101997`, simplify `0.125387`;
- same-condition rewritten classification retains residual author signal, but less strongly than the frozen passage-level split;
- distance contraction remains stable: all-feature ratios remain below 1.0 for paraphrase, modernize, and simplify.

Manuscript implication:

> E2 supports the main result cautiously. It weakens any overstrong claim that the classifier captures pure authorial style independent of work, but it strengthens the paper by honestly showing that rewrite-associated separability loss persists under a stricter cross-work test.

## E3 completion summary

E3 generated and committed the warning-row sensitivity package in commit `34c07109bcb01417b0ffdb0063c7126d55632908`, then was regenerated through the fresh workflow with proof log `logs/e3_warning_row_sensitivity_workflow_proof.md`.

Main result:

- paired-passage bootstrap intervals for nearest-centroid test losses stay positive under all three subsets;
- all-feature and function-word inter-author distance ratios remain below 1.0 for all rewrite conditions under all three subsets;
- QC-pass-only filtering reduces rows but keeps all six authors represented in every condition.

## E7 completion summary

E7 generated and committed the length-band robustness package in commit `94c19220381aa8e4a00613024bf07c232b08a5c4`, with workflow proof log `logs/e7_length_band_robustness_workflow_proof.md`.

Main result:

- source-original length band `501_575` has 42 test rows per condition and shows positive nearest-centroid losses: paraphrase `0.365744`, modernize `0.228224`, simplify `0.360043`;
- source-original length band `576_650` has 12 test rows per condition and shows positive nearest-centroid losses: paraphrase `0.422222`, modernize `0.160317`, simplify `0.238889`;
- actual-text-length grouping reveals that rewrites often shift into shorter bands, including the `450_500` band where no original baseline exists;
- therefore E7 supports robustness across comparable original-length strata, but does not justify saying length is irrelevant.

Manuscript implication:

> E7 supports the main result against a simple original-length confound, but the paper must acknowledge that length shift is part of the rewriting intervention.

## Status rule

No extension experiment may be marked complete unless it leaves:

1. a protocol or design note;
2. machine-readable output files;
3. a manifest or summary CSV;
4. a human-readable log report;
5. a checker script or audit note where practical.

## Manuscript use

These experiments should be framed in the eventual manuscript as reviewer-facing robustness evidence, not as a second main contribution. The paper should still remain focused on controlled rewriting and the measurability of literary authorial style.

E3 can now be cited in the manuscript as evidence that retained QC warning rows do not drive the main separability-loss result.

E2 can now be cited as a stricter cross-work validation, but only with cautious wording: cross-work original classification is moderate, while rewrite-associated loss and distance contraction persist.

E7 can now be cited as a length-band robustness test, but only with cautious wording: the transfer-loss pattern persists across comparable source-original length bands, while actual rewritten lengths often shift shorter.

E8 must not be cited until the workflow-generated outputs and proof log exist.
