## Purpose

Earlier feature-family analyses show which families are vulnerable when used alone. E8 asks a different question:

> Which feature families actually drive the full-system transfer result?

A feature family can be weak alone but still matter in the full model. Conversely, a family can perform well alone but be redundant once other features are included. E8 therefore trains the nearest-centroid transfer classifier on the full feature set and then on full features **minus one family at a time**.

## Ablation modes

| ablation_mode | Included features | Purpose |
|---|---|---|
| `full_features` | all 205 features | full nearest-centroid baseline |
| `minus_<family>` | all features except one family | tests dependence on that family |

## Analysis design

For each ablation mode:

1. train nearest-centroid on original-condition training rows;
2. evaluate original, paraphrase, modernize, and simplify on validation and test splits;
3. report accuracy, macro-F1, weighted F1, and loss versus original;
4. compare each `minus_<family>` condition against the `full_features` baseline.

## Interpretation rules

E8 supports the paper if no single family removal completely destroys the full-system degradation pattern. It is especially useful if removing `char3` or `function_word` sharply changes the magnitude of loss, because those families are often central to stylometric authorship attribution.

Possible manuscript interpretations:

| Outcome | Interpretation |
|---|---|
| Removing one family strongly reduces original macro-F1. | That family drives author recognition in the full model. |
| Removing one family strongly reduces rewrite-loss magnitude. | The rewrite-loss story depends heavily on that family. |
| Loss remains positive after every single-family removal. | The degradation pattern is distributed across feature families rather than an artifact of one family. |
| One condition reverses after a family is removed. | Report the exception and narrow the claim. |

## Pass condition

The checker validates structural completeness and full coverage of all feature families. It does not require the scientific result to be favorable.

## Manuscript use

E8 should be reported as an ablation robustness test:

> A leave-one-feature-family-out ablation retrained the nearest-centroid transfer classifier after removing each feature family from the full representation. This tested whether the observed transfer degradation was driven by a single stylometric feature family or distributed across the representation.

Use outcome-specific wording only after the workflow-generated outputs exist and have been inspected.
