# Historical material

This folder preserves the repository's earlier public contents from commit
`c2428aeb6644380946807d60a4c4edfecc8a83b3` before the current research audit
layout was introduced. Its reports and completion claims belong to that earlier
experiment. Start at the repository root README and `audit/README.md` for the
current six-arm evidence.

Historical workflows are stored here rather than under the active root
`.github/workflows/` directory. Historical scripts and their original file paths
may require checking out their original commit to reproduce that version.
This folder does not contain the current manuscript.
